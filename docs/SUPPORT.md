Include device model, Android/Fire OS version, app version and reproduction steps. Do not post private notes, personal books, documents or backup files to a public issue.

If voice is unavailable, type the command in Voice or use touch controls. Android speech services differ across Fire tablets. Install or configure an engine only through a trusted system-supported route.

For imports, choose a personal PDF or unencrypted DRM-free EPUB under 100 MB. Rejected archives may have unsafe names, encrypted resources, oversized entries or excessive expansion. Scanned PDFs are page images; there is no OCR. The PDF renderer does not provide text selection, text highlighting, search or read-aloud.

To preserve data before reinstalling, export JSON and keep your original document files separately. Import JSON merges records by ID. Existing local document references stay attached to matching records. New imported book records need their original document imported again; document binaries are never embedded in JSON backups.

Exports are unencrypted. The destination may be a third-party storage service selected by the user. Delete all data removes local records and imported documents, but does not remove exports saved elsewhere.
