# Reading Habit Coach 0.1.0 — early access

An installable native Android preview by **O. Bankole**.

Track books and reading sessions, keep a private journal, set gentle daily/weekly intentions, view stored-data insights, and read supported personal PDFs and DRM-free EPUBs. Touch/text commands work without speech-recognition services. Optional encrypted local backup is included.

Tested on a Fire tablet (KFTRWI, Android API 28) in portrait and landscape. Debug build, Android lint and 19 unit tests pass. An earlier build passed all three device tests; the final build passed both data/import tests, while its interactive rerun remains pending user unlock of the tablet. The companion GitHub Pages website includes privacy and support information.

This **does not complete the production master brief**. Amazon purchases and receipt verification, complete multilingual UI, cloud backup, advanced PDF text tools and additional goal/analytics features remain unfinished. Read [RELEASE-STATUS.md](https://github.com/lanray07/Reading-Habit-Coach/blob/main/docs/RELEASE-STATUS.md) for the complete gap list.

The APK is debug-signed for early-access testing. Production signing and Amazon Appstore submission are not configured. No charges or free-trial purchases are taken by this build. Speech recognition and read-aloud depend on installed device services; real speech-engine acceptance testing remains pending.

Original sample EPUB content and screenshots are included in the repository. The installable APK starts with an empty private library; QA fixtures are not automatically loaded.

Support: [banksmi@mail.com](mailto:banksmi@mail.com). Do not post private notes, books or backups to public GitHub issues.
