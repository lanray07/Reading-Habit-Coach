# Reading Habit Coach privacy notice — draft

Version 0.1.0 early access · 20 October 2026

Publisher: **O. Bankole**. Privacy and support contact: **banksmi@mail.com**.

Reading Habit Coach stores book records, reading sessions, notes, highlights, goals, preferences and imported documents on your device. No account is required. The app has no third-party analytics or advertising SDK and does not upload reading history, notes or documents for analytics. Automatic Android cloud backup and device-transfer backup are excluded in the app configuration.

Optional metadata search sends only your entered search terms to Open Library over HTTPS. Use manual entry if you prefer not to use this online service. Readium renders compatible imported EPUBs; Android PdfRenderer renders PDF pages. The app does not access Kindle purchases or bypass DRM.

The microphone is used only after you request a spoken command. This app does not save microphone recordings or listen continuously. Installed Android speech-recognition services may process audio online under their own policies. Text-to-speech availability, installed voices and network requirements depend on the chosen engine. Touch controls and typed commands remain available without microphone access.

Notification permission is optional. Reading reminders use approximate operating-system scheduling and fixed quiet hours. Notification settings can be changed in the app and in device settings.

Exports are saved to a destination you choose with Android's document picker. That destination may be another service such as a cloud drive. Ordinary JSON, CSV, Markdown, plain-text and PDF exports are unencrypted. Optional local encrypted backups use AES-256-GCM and a user-chosen passphrase derived through PBKDF2-HMAC-SHA256 with 210,000 iterations and a random salt. Passphrases are not stored and cannot be recovered. Backups include records and notes, not the original document files.

Records remain until you delete them, clear app storage or uninstall. The Delete all local data action requires confirmation and removes local records and imported documents. It cannot delete exports previously saved elsewhere. Keep original personal documents separately if you want to reopen them after restoring a metadata backup.

There is no active checkout, store receipt processing, configured subscription, cloud backup provider or optional content-translation service in this build. The interface is currently English. Translation tooling runs only during development; it does not translate user books or notes.

The companion GitHub Pages website has no application tracking scripts or contact-form database. GitHub may process hosting request data under its own service policies. Email support and GitHub issues are user-initiated; do not include private documents, notes or backup files in public issues.

This notice describes the early-access implementation and requires final publisher review before a production release. A material change to data handling requires an updated notice.
